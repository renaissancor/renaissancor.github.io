# Physical Layer & Data Link Layer

Almost every wired LAN is **Ethernet**: the physical layer defines how bits become signals on the cable, the data link layer defines the frame format. Both are standardized as **IEEE 802.3** (variants are lettered: 802.3u, 802.3ab, ...).

### Naming: `<speed> BASE - <medium>`

`100BASE-T` = 100 Mbps, baseband, twisted pair. `10GBASE-T` = 10 Gbps. A bare number is Mbps, `G` is Gbps. **BASE** = baseband signaling.

| suffix | medium |
|---|---|
| `C` | coaxial |
| `T` | twisted pair (copper) |
| `S` | fiber, short wavelength |
| `L` | fiber, long wavelength |

Generations: Fast Ethernet 100 Mbps → Gigabit 1 Gbps → 10 Gigabit 10 Gbps.

### Ethernet Frame

```
|<-----------------------Header----------------------->|<----Payload---->|<-Trailer->|
| Preamble | Receiver MAC | Sender MAC | Type / Length |       Data      |    FCS    |
| 8 Bytes  |    6 Bytes   |  6 Bytes   |  2 Bytes      | 46 ~ 1500 Bytes |  4 Bytes  |
```

| field | size | role |
|---|---:|---|
| Preamble | 8 B | 7 bytes of `10101010` for clock sync, then 1 byte `10101011` (SFD) marking the start |
| Receiver MAC | 6 B | destination NIC; `FF:FF:FF:FF:FF:FF` = broadcast |
| Sender MAC | 6 B | source NIC |
| Type / Length | 2 B | ≤ 1500 (`0x05DC`): payload length. ≥ 1536 (`0x0600`): EtherType, the protocol inside |
| Data | 46–1500 B | the upper-layer packet; padded with zeros up to 46 B |
| FCS | 4 B | CRC over the frame; a mismatch means the frame is dropped |

| EtherType | protocol |
|---|---|
| `0x0800` | IPv4 |
| `0x86DD` | IPv6 |
| `0x0806` | ARP |

### MAC Address

48 bits, assigned per network interface (one PC can have several), meant to be unique and fixed. It identifies the sender and receiver **inside one LAN**.

Windows

```shell
getmac /v  
ipconfig /all 
``` 

UNIX (Linux, macOS)

```shell
ifconfig   
```

### NIC and Cables

- **NIC** (Network Interface Controller) connects the host to the medium. It drops frames whose destination MAC is not its own and frames that fail the FCS. Its speed (10 Mbps–100 Gbps) caps the host's link speed. Once a card, now usually on the motherboard.
- **Twisted pair**: copper, 4 pairs / 8 wires, RJ-45 connector. Copper picks up noise, hence shielding, named `XX/YTP`: `XX` = overall shield, `Y` = per-pair shield (U none, S braid, F foil). UTP = no shield at all.
- **Fiber**: light instead of current. Faster, longer distance, nearly immune to noise. Used for long-haul and intercontinental links.

### Hub vs Switch

| | Hub | Switch |
|---|---|---|
| layer | 1, physical: no notion of address | 2, data link: reads MAC addresses |
| forwarding | repeats every signal out of **every** other port | sends the frame to **the one port** of the receiver |
| duplex | half (one direction at a time) | full (both at once) |
| collision domain | all hosts share one | one per port, so no collisions |

A **repeater** only amplifies a weakened signal; a hub is a multi-port repeater.

**CSMA/CD** is how half duplex copes with collisions: listen before sending (carrier sense); if a collision is detected anyway, stop, send a jam signal, wait a **random** time, retry. Different random waits make a second collision unlikely. Full-duplex switches made it unnecessary.

### How a Switch Learns MAC Addresses

1. **Learning**: on every incoming frame, record *sender MAC → arrival port* in the MAC address table.
2. **Flooding**: destination not in the table yet → send out every port, like a hub. Wrong NICs drop it.
3. **Forwarding / filtering**: destination known → send only to its port.
4. **Aging**: entries expire if not refreshed.

A **bridge** does the same learning with fewer ports; the device is rare now, the concept is not. "Switch" alone means an L2 switch; L3/L4 switches add routing or transport functions.

### VLAN

One physical switch split into several logical LANs, so broadcasts and flooding stay inside each group.

- **Port-based (static)**, the common one: ports 1–6 → VLAN A, 7–10 → VLAN B.
- **MAC-based (dynamic)**: the sender's MAC decides the VLAN.
