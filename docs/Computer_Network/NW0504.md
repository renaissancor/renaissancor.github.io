# Microscopic View of Networks

### 2.1 Network Protocols

```
    Visual: Protocol Communication
    
    Computer A                 Computer B
    ----------                 ----------
    Application                Application
        ↓                          ↑
    Protocol                    Protocol
    Processing                  Processing
        ↓                          ↑
    Network                     Network
    Interface                   Interface
        ↓                          ↑
        -----------------------------
                    Network
```

A protocol is the agreed format and procedure for exchanging data. Many run at once, each with one job:

| protocol | job |
|---|---|
| **IP** | route packets to the destination host |
| **ARP** | find the MAC address for an IP address |
| **TCP / UDP** | deliver to a process: reliable vs fast |
| **HTTP / HTTPS** | web requests; HTTPS adds encryption |

### 2.2 Network Reference Models

#### OSI Model (7 Layers)

```
    Visual: OSI Model Layers
    
    +-------------------------+
    | 7. Application Layer    | <- User interface, access to network services
    +-------------------------+
    | 6. Presentation Layer   | <- Data formatting, encryption
    +-------------------------+
    | 5. Session Layer        | <- Session establishment, maintenance
    +-------------------------+
    | 4. Transport Layer      | <- End-to-end connections, reliability
    +-------------------------+
    | 3. Network Layer        | <- Routing, IP addressing
    +-------------------------+
    | 2. Data Link Layer      | <- Physical addressing, access to media
    +-------------------------+
    | 1. Physical Layer       | <- Bit transmission, physical connections
    +-------------------------+
```

#### TCP/IP Model (4 Layers)

```
    Visual: TCP/IP Model vs OSI Model
    +-------------------------+    +-------------------------+
    |                         |    | 7. Application Layer    |
    |                         |    +-------------------------+
    | 4. Application Layer    |    | 6. Presentation Layer   |
    |                         |    +-------------------------+
    |                         |    | 5. Session Layer        |
    +-------------------------+    +-------------------------+
    | 3. Transport Layer      |    | 4. Transport Layer      |
    +-------------------------+    +-------------------------+
    | 2. Internet Layer       |    | 3. Network Layer        |
    +-------------------------+    +-------------------------+
    |                         |    | 2. Data Link Layer      |
    | 1. Network Access Layer |    +-------------------------+
    |                         |    | 1. Physical Layer       |
    +-------------------------+    +-------------------------+
          TCP/IP Model                   OSI Model
```

TCP/IP merges OSI 5–7 into Application and 1–2 into Network Access. The extended TCP/IP model splits Network Access back into Physical and Data Link.

### 2.3 Encapsulation and Decapsulation

#### Encapsulation (Sending)

```
Application Layer                     +--------+
                                      |  Data  |
                                      +--------+
                                        ↓
Transport Layer                   +------------+
                                  |Hdr|  Data  |
                                  +------------+
                                        ↓
Network Layer                 +----------------+
                              |IP |Hdr|  Data  |
                              +----------------+
                                        ↓
Data Link Layer           +-----------------------------+
                          |MAC|IP |Hdr|  Data  |  FCS   |
                          +-----------------------------+
                                        ↓
Physical Layer            0101010101010101010101010101010101

```

Going down, each layer wraps the PDU from above as its payload and adds its own header (Data Link also adds the FCS trailer). Boxes inside boxes.

#### Decapsulation (Receiving)

```
Application Layer                     +--------+
                                      |  Data  |
                                      +--------+
                                        ↑
Transport Layer                   +------------+
                                  |Hdr|  Data  |
                                  +------------+
                                        ↑
Network Layer                 +----------------+
                              |IP |Hdr|  Data  |
                              +----------------+
                                        ↑
Data Link Layer           +-----------------------------+
                          |MAC|IP |Hdr|  Data  |  FCS   |
                          +-----------------------------+
                                        ↑
Physical Layer            0101010101010101010101010101010101
```

Going up, each layer strips its header and hands the payload to the layer above, until the original data reaches the application.

### 2.4 Protocol Data Units (PDUs)

```
    Visual: Protocol Data Units
    
    OSI Layer            PDU
    ---------            ---
    Application  }
    Presentation } ---> Data
    Session      }
    
    Transport    -----> Segment/Datagram
    
    Network      -----> Packet
    
    Data Link    -----> Frame
    
    Physical     -----> Bit
```

### 2.5 Practical Considerations

- The models are maps, not rules. Real protocols straddle layers: ARP is called "layer 2.5", routers touch more than layer 3.
- For engineering, knowing what each protocol and device does beats memorizing the layer numbers. The numbers matter mostly in exams and interviews.
