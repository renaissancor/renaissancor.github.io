    Macroscopic View of Networks

    1.1 Basic Network Structure

    A network is a graph: nodes are devices, edges are links.

        Visual: Network as a Graph

    [Desktop] --------- [Router] --------- [Server]
        |                  |                  |
        |                  |                  |
    [Laptop] ---------- [Switch] --------- [Printer]
                          |
                          |
                      [Smartphone]
    • Edge nodes: end devices (PC, phone, server).
    • Intermediate nodes: devices that forward (router, switch).

    1.2 Network Components

    Hosts

        Visual: Client-Server Interaction

    Client                       Server
    ------                       ------
    [Browser]                    [Web Server]
        |                            |
        |------ Request: GET ------->|
        |                            |
        |<---- Response: HTML ------ |
    • Client requests, server responds.
    • A role, not a device: one machine can be both, depending on the operation.

    Network Devices

        Visual: Network Devices

    [Host A] --- [Switch] --- [Host B]
                    |
                    |
    [Host C] --- [Router] --- [Internet]
                    |
                    |
    [Host D] --- [WiFi AP] --- [Mobile]

    Intermediate nodes whose only job is forwarding: hub, switch, router, Wi-Fi access point.

    Edges and Messages

    • Edge (link): wired (Ethernet) or wireless (Wi-Fi). Its characteristics set the performance.
    • Message: what travels over the links: web page, file, email.

    1.3 Network Classifications

    By Geographic Scope

        Visual: Network Types by Scope

    +----------+              +----------+
    |   LAN    |              |   LAN    |
    | (Office) |              |  (Home)  |
    +----------+              +----------+
         |                         |
         |                         |
    +----------+              +----------+
    |   MAN    |--------------|   WAN    |--------------- Internet
    |  (City)  |              | (Global) |
    +----------+              +----------+
         |
         |
    +----------+
    |   CAN    |
    | (Campus) |
    +----------+
    scope
    LAN home, office
    CAN campus, several buildings
    MAN city
    WAN country to global. The Internet is a WAN of LANs

    By Message Exchange Method

    1. Circuit switching
        Visual: Circuit Switching

    [A] ------- [B] ------- [C]
     |           |           |
     |           |           |
    [D] ------- [E] ------- [F]

    Dedicated path A→B→C is reserved for the entire session
    Path D→E→F cannot use B→C even if available

    A dedicated path is reserved for the whole session. Stable rate, wasted capacity when idle.

    1. Packet switching
        Visual: Packet Switching

    [A] ------- [B] ------- [C]
     |           |           |
     |           |           |
    [D] ------- [E] ------- [F]

    Packet 1: A→B→C
    Packet 2: A→D→E→F→C
    Packet 3: A→B→E→C

    The message is cut into packets; each may take a different path. Efficient use of links. The Internet works this way.

    1.4 Packet Structure

        Visual: Packet Structure

    +--------+-------------------+--------+
    | Header |      Payload      | Trailer|
    +--------+-------------------+--------+
       |            |                |
       |            |                |
    Control      Actual           Error
    Info         Data            Checking
    (Address)

    Like a parcel: payload is the content, header / trailer is the label (addresses, routing) and the damage check.

    1.5 Transmission Methods

        Visual: Transmission Methods

    Unicast:        Broadcast:
    [S] → [R]       [S] → [R1]
                     ↓    ↓
                    [R2] [R3]

    Multicast:      Anycast:
    [S] → [R1]      [S] → [Nearest R]
     ↓     
    [R2]   [R3]
    to whom
    Unicast one receiver (most traffic)
    Broadcast every host in the network
    Multicast a subscribed group
    Anycast the nearest member of a group
